# 1.15.0 part A: status perks balance (bot)

Bot: half Renovations, `rare` door policy, 60 runs per cell (same seeds across cells), perk forced at run start, bot picks the rest.
Clear-rate noise is about ±6 points at 60 runs. The bot plays worse than people: compare cells with each other only.

I did not retune card numbers (the review fixed them); this is flagged for the planner: the cheapest lever is Leaky Pen / Cold Storage level 1 strength.
