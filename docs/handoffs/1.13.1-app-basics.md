## Why
iPhone Safari never offers "install" and can delete a website's saved data (localStorage) after ~7 days unused; Home Screen apps
are exempt. Players have no way to back up or move progress. The game also needs the network to open.

## Items
1. **Home Screen nudge (high).** After the player's first cleared story wing (or first finished run of ≥ 3 minutes, whichever
   comes first), show once a friendly card: "Add Overdue! to your Home Screen to keep your progress safe" with the two Safari
   steps (Share button → "Add to Home Screen"), plus "Got it" and "Don't show again". Never show it when already running as an
   installed app (`navigator.standalone === true` or `matchMedia('(display-mode: standalone)').matches`). Flags in the tips store
   `overdue.tips.v1`, additively. Don't change the app name or icon (CLAUDE.md).
2. **Save backup code (high).** Settings → "Backup progress": "Copy backup code" (all player keys: `overdue.settings.v1`,
   `overdue.best.v1`, `overdue.name.v1`, `overdue.halloffame.v1`, `overdue.codex.v1`, `overdue.progress.v1`, `overdue.tips.v1`)
   as one compact text code (versioned, e.g. `OVD1:` + base64 of JSON, with a checksum); copy via the clipboard API inside the
   click, falling back to a selectable text box. "Restore from code": paste box + an in-page confirm step ("This replaces your
   progress on this phone"). Validate the code fully before writing anything; run `normalizeProgress()` on restore; a bad or
   truncated code shows a clear error and changes nothing. Put encode/decode/validate in a pure module with unit tests
   (round-trip, bad checksum, wrong version, missing keys, junk input). Keep Settings fitting at all QA sizes.
3. **Offline play (medium).** Add a service worker:
   - Cache-first for the game page, icons and manifest; the game opens with no network after one online visit.
   - Updates: keep the existing `version.json` check and the existing "new version — tap to reload" update bar; the SW
     fetches the new build in the background and the reload switches to it. A new version must reliably replace the old one.
   - Kill switch: a newer release can unregister the worker (document how in README).
   - Works on GitHub Pages under `/overdue/` (scope/paths) and in `npm run dev`; the claude.ai-hosted `--fragment` build must not
     register a worker.
   - QA: (a) load once, `context.setOffline(true)`, reload → title screen appears and a run starts; (b) serve version N, load,
     then serve N+1 → update bar appears and after reload the title shows N+1.
4. **Sound check is already done** in 1.12.1; nothing to do.
