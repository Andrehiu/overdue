## The 3 options (URL switch `?art=a|b|c`, default = today's look, so `main` behaviour is unchanged without the flag)
| Flag | Option | Build from the spec |
|---|---|---|
| `art=a` | **Shapes** | Direction 1 "Shape Alphabet" as written (own silhouette per type, size ladder, elite = gold outline on own shape + crown) |
| `art=b` | **Characters** | Direction 2 "Cast of Characters" as written (own face language per type, elites with red irises) |
| `art=c` | **Blend** (art director's recommendation) | Direction 2's characters drawn on Direction 1's silhouettes and size ladder, plus Direction 3's bunny hop and the patron's ripple before it shouts. No other Direction 3 trails |
| `&eyes=1` (any option) | Glowing eyes in the dark | Direction 3's tiny per-type eyes drawn above the light layer, no blur. Separate yes/no for the owner (it touches the lighting rule), so it must be off unless the flag is set |

Implementation rules:
- **Cache sprites**: pre-render each type/animation frame/flash state into offscreen canvases once (by option and elite), then
  `drawImage` per enemy. No `shadowBlur`/`filter` per entity per frame.
- **Hitboxes unchanged** (`DEF.r` stays); visual size may differ per the size ladder.
- Keep gameplay tells: white hit flash, elite red flare before firing, patron charge-up before shouting, golem HP bar.
- Colours: use the spec's fixes for **bunny, notice and worm** (verified with `isEnemyHue`). **Keep the golem and coin gold**
  (gold means fines everywhere in the HUD); ignore the spec's golem/coin hue change.
- Lighting code untouched (except the `eyes=1` overlay pass). Endless/story logic untouched: this is drawing code only.
- Keep the code tidy: put the option drawing in a new module if it is big (e.g. `src/enemy-art.js`, pure canvas functions),
  with `drawEnemy()` dispatching on the option. A later session will delete the two losing options.
