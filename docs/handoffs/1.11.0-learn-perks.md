## Changes (owner-approved; keep the scope to these)
Each tip below shows **once per player ever**, stored in a NEW localStorage key `overdue.tips.v1` (e.g. `{ seen: ["perk-stack", …] }`;
additive: don't touch existing keys). Tips are one short line in a strip **above** the cards (never covering cards, never blocking
taps), styled with component-scoped tokens, readable on iPhone landscape (750x342 in QA).
1. **First perk screen ever** → tip: "Perks stack to ●●●. Max one to unlock its Masterwork." (id `perk-stack`)
2. **Masterwork previews (always, not one-time tips):**
   - The card that would take a perk to **2/3** shows "Next level unlocks a Masterwork 🔒".
   - The card that would take it to **3/3** keeps today's "Unlocks <Masterwork name>" (name visible).
   - Never reveal a Masterwork's effect before it's unlocked. First time this appears, also show tip id `masterwork-near`:
   "One more level and this perk's Masterwork joins the deck."
3. **First card that pairs with an owned perk** (today's 🔗 hint): make the 🔗 line pulse briefly (respect reduced-motion) and show tip
   `combo-pair`: "Two perks that pair unlock a Collected Work."
4. **Special cards explain themselves (always):** a Masterwork or combo card in slot 1 gets an "UNLOCKED" stamp (the card already
   has a stamp area: reuse it) and a reason line: "because 📕 Hardcover hit 3/3" or "because you own 🧭 Dewey + 🔖 Bookmark"
   (use `short` names + icons). First time ever, also tip `special-unlocked`: "Unlocked cards always take the first slot until you pick them."
5. **After the first special is taken**: toast "📚 Added to your Library Codex (title screen)" (tip id `codex`), once ever.
6. **Level-up cards (always):** a card for a perk you own shows "●●○ → ●●●" style (current → after) instead of only the after-pips.
7. **How to play:** a short "Perks" box (3 lines, can be a compact row of tokens): "●○○ → ●●● = Masterwork" · "Perk A + Perk B =
   Collected Work" · "Each special: once per run". Must still fit with the pinned Back row (QA pinned-row + contrast checks).
8. **Settings:** button "Show tips again" (resets `overdue.tips.v1`), placed near Reset progress; Settings must still fit.
